| الحارس | ما يمنعه |
| --- | --- |
| `DestinationDoorTest` | وجهة مرئية بلا باب · مسار مكرّر · أب غير مسجَّل |
| `LaunchRouteTest` | أداة في صفحة التحكّم بلا مسار صالح · إسقاط `MaxBackup`/`Permissions` |
