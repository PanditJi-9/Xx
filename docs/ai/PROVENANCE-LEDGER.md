# سجلّ النسب — بصمة أصل لكل إصدار منشور

> **الغاية:** أن يكون في يد المالك **دليل** لا شكّ: أي حزمة ظهرت تحمل `MMPROV-…` تعود إلى إصدار
> بعينه والتزام بعينه. والتفصيل والحدود في `docs/ai/ANTI-COPY-2026-11.md` §٥ وقراره `ADR-95`.

## كيف تُقرأ البصمة

`build.gradle.kts` يشتقّ `BUILD_MARK` = `MMPROV-` + ١٦ خانة hex من
`versionName|versionCode|زمن التزام git`. أي أنها **تتغيّر مع كل إصدار**، وتثبت عند إعادة بناء
الالتزام نفسه. وتُستهلك في مقدّمة سكربت التشخيص، فتظهر في كل سجلّ تشخيص يُصدَّر من التطبيق.

## كيف يُسجَّل إصدار

بعد بناء حزمة الإصدار الموقّعة (على جهاز البناء، لا هنا):

```sh
python3 tools/build_watermark.py --record app-release.apk --version V5.0 --commit "$(git rev-parse HEAD)"
```

ولفحص حزمة مشكوك فيها:

```sh
python3 tools/build_watermark.py --scan suspect.apk
```
